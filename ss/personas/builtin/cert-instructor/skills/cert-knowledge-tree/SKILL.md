# 考纲 → 知识点树 抽取规范

输入：用户粘贴的考纲文本、导入的考纲 PDF（已按页切片）或 Markdown 大纲。
输出 JSON：`{"sections": [{"title": 章, "children": [{"title": 节, "children": [{"title": 点}]}]}]}`。

抽取纪律：① 节点名用考纲原文措辞，不改写不缩写；② 层级判定以考纲编号体系为准（一/（一）/1.）；
③ 拿不准归属的点挂到最近的章节并标记 `ambiguous: true`，宁缺毋滥；④ 目标质量线：1000 字考纲
→ ≥2 层、≥15 个节点（PRD CERT-02 验收 1）；⑤ 应用侧会把树与覆盖率/错题数关联，你不需要维护
计数，只负责结构正确。
