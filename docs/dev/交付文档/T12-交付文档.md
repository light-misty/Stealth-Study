## 3. 关键实现决策与差异登记

| # | 位置 | 差异/解释 | 依据 |
|---|---|---|---|
| 3-1 | H4 | 模型输出不可解析时返回 `MODEL_OUTPUT_INVALID`（502）；03 §4.8 H4 错误列仅列 `MODEL_NOT_CONFIGURED`/`MODEL_TIMEOUT`，本实现沿用全错误码表的既有代码，未新增码 | 03 §6 已有码；与 library.py 的 provider 异常映射一致 |
| 3-2 | H4 | `doc_id` 输入：缺失/越权 → `DOC_NOT_FOUND`，无文字层 → `DOC_SCAN_EMPTY`，未解析完 → `DOC_NOT_READY`（03 未列，复用同文档族既有码）；拼接文本截断 `TREE_MAX_CHARS=20000` | 06 §4 切片口径的防护上限 |
| 3-3 | H9 | 目标节点已错过的触发点**不建**（`compute_next_run` 对过去的一次性任务返回 None，建了也永不触发，只会污染自动化列表）；全部错过时 `automation_ids=[]`。03 的 `automation_ids: [3个]` 在考试日 ≥30 天后时严格成立 | PRD §13 `automation/models.py:71-75` 复核结论 |
| 3-4 | H9 | 幂等：`automation_ids` 非空时直接返回已存 id，不重复建（03 未要求，防双击重复任务） | 与 T13 模板幂等验收同思路 |
| 3-5 | H9 | 未知/越权节点：缺失 → `ITEM_NOT_FOUND`（404，消息覆写"考试节点不存在"），越权 → `FORBIDDEN_PROFILE`。03 §6 无 `DEADLINE_NOT_FOUND`，未新增错误码 | 错误码表闭合性优先 |
| 3-6 | H3 | 成环（自父/挂到后代）拒绝为 `ILLEGAL_TRANSITION`（409）；03 未列该错误——树 UI 正常操作不会触达，属 API 层防御 | 防 H1 渲染出现环数据 |
| 3-7 | C1 响应 | 返回 03 §4.3 GradeResult 视图（`attempt_id`/`degrade_level`/`rubric`/`dimensions`/`errors`/`model_answer_outline`/`model_used`/`notice`）并**附** `band`/`score`/`max_score`/`scoring_points`/`grading_json` 附加字段，使 CERT-07 得分点三态在 C1 单次响应内可用（C2/C3 尚未交付） | TS `GradeResult` 为超集兼容（附加字段不破坏契约） |
| 3-8 | C1 | 无 `question_id` 时 attempt `subject="general"`、`question_id=NULL`，`session_type="grading"`；与 E5 相同的"attempt 先落、批改失败也保留"语义 | 03 §4.5 E5 语义、02 §4.13 |
| 3-9 | C1 | `rubric_id` 合法值 = `RUBRICS` 三条命名标准（cet_essay / cet_translation / cert_scoring_points）；`custom_rubric` 与 `rubric_id` 同给时自定义文本获胜 | 06 §3.5 |
| 3-10 | H6 | `coverage` = 有点级掌握度记录的点 / 全部点（"覆盖率进度"口径，三态中 unknown 也算已评估）；`weak_top5` 只含 unknown/fuzzy、unknown 优先，按标题稳定排序；维度行不参与 | PRD CERT-03 "掌握度三态标记 + 覆盖率进度" |
| 3-11 | H1 | `question_count`/`mistake_count` 请求时对账实时 COUNT，不维护冗余计数列（列保留默认值） | 计数真实性优先，02 §4.7 列保留 |
| 3-12 | 路由 | H3/H9 路径参数命名 `{point_id}`/`{deadline_id}`（非 `{id}`）：`ProfileGuard` 把路径参数 `pid`/`profile_id` 视为档案 id，子资源参数沿用 T09 `{qid}` 的命名纪律 | T06 横切设计 |

### 4.3 异常输入与边界覆盖（抽样）

- 守卫横切：`PROFILE_REQUIRED`（缺 profile_id）、`PROFILE_NOT_FOUND`（伪造）、`FORBIDDEN_PROFILE`
  （跨档案知识点/题目/节点）、`PROFILE_READ_ONLY`（结课档案拒写）——每组端点均有负例；
- 校验类：未知 `node_type`/`kind`（422）、坏日期格式（422）、空白 title/answer（422）、
  未知 body 字段（422，`extra="forbid"`）、未知 `level`（`INVALID_LEVEL` 400）、
  未知 `rubric_id`（`RUBRIC_NOT_FOUND` 404）；
- 模型故障：超时（`MODEL_TIMEOUT` 504 retryable，attempt 保留）、不可解析输出
  （`MODEL_OUTPUT_INVALID` 502，H4 事务回滚零残留）、未配置模型（`MODEL_NOT_CONFIGURED` 409，零写入）；
- 自动化边界：无 TaskStore（`AUTOMATION_UNAVAILABLE` 503）、重复安装幂等、错过触发点跳过、
  全部错过返回空数组。
