## 3. 关键实现说明

### 3.1 `flags.ts`（S1）

```ts
export const showLogin = () => flag("ocw.flag.login", false);
```

复用既有 `flag(key, fallback)`（localStorage），零新增依赖；不写 `config.toml`（ADR-04 扁平 KV 陷阱）。

### 3.2 `Sidebar.tsx`（S2）

| 子项 | 改法 |
|---|---|
| 账户菜单未登录分支 | `cloud?.signed_in ? (…) : showLogin() ? (未登录提示 + 登录按钮) : null` |
| 登出菜单项 | `cloud?.signed_in && showLogin() && …` |
| 账户行文案 | `showLogin() ? t("sidebar.not_signed_in_row") : t("sidebar.local_workspace")` |

`sidebar.local_workspace`（「本地工作区」/「Local workspace」）为本次 zh/en 同步新增的 1 个 key，保持 `locales.test.ts` 的 key 集合严格相等门禁。

### 3.3 `Onboarding.tsx`（S3）

登录带整块（`signin_for_oneclick` 文案带 + `ob-cloud-signin` 按钮 + 已登录态 `ob-tools-signedin`）包 `showLogin() &&`；footer 双态改判 `cloud?.signed_in && showLogin()`，关闭时落到「继续（不登录）」分支，step 1 → step 2 仍可正常推进。step 1 的 provider 表单（仅 API Key）**保留**（PRD §3.3.3 边界定义）。

### 3.4 全量复扫新增的 6 处收口（S5）

首轮按 `01 §6` #8 的三处改完后，以「`cloudLogin` / `waitForCloudSignIn` / `CloudSignInInline` / `cloud.signed_in` 条件渲染」为检索面做全仓复扫，发现**仍有 6 处可点到的登录入口**，均不在首轮清单内：

| # | 文件 | 位置 | 关闭后行为 |
|---|---|---|---|
| 1 | `components/connectors/CloudSignIn.tsx` | `CloudSignInInline` 本体 | 拆出内层 `CloudSignInButton`（承载 `waiting` 状态与 `inline-cloud-sign-in` 按钮），外壳 `if (!showLogin()) return null` |
| 2 | `components/connectors/AddConnectionModal.tsx` | 四个一键面板（Generic/Slack/Github/HubSpot） | `cloud && showLogin()` 落空 → 走 `CloudStatusPending` |
| 3 | `components/ManageTabs.tsx` | `ConnectSetup` 托管块 | 同上 |
| 4 | `components/AutomationQuickstart.tsx` | `ob-cloudpane` 懒登录带 | 整块不渲染，连接行保持可点（不再弹登录） |
| 5 | `components/GalleryModal.tsx` | `gallery-signin` 卡 | 整卡不渲染 |
| 6 | `providers/ProviderSetup.tsx` | `OAuthSignIn`（`info.auth === "oauth"`） | 不渲染；**仅**针对模型提供商的 codex 浏览器授权，非产品登录，但同属可点浏览器授权入口，一并收口 |

统一原则：关闭态**回落到 Manual 手填路径或 pending 态**，不留空白、不报错。这 6 处全为「条件渲染短路」，**无新增侵入点注册**：`01 §6` #8 的定义域即「登录入口在既有组件中的显隐短路」，本次属该侵入点的展开实现，全仓侵入点总数仍为 9 处。

### 3.5 后端总闸 `campus.login_enabled`（S6）

首轮结论「后端零改动」经复核修正：`ss/server/app.py` 确实存在 `/v1/cloud/login`、`/v1/cloud/logout`、`/auth/callback` 三条**可被直接调用的**端点（`ss/cloud.py` 提供实现）。前端隐藏不足以「完全失效」，因此补服务端总闸：

| 层 | 改动 |
|---|---|
| `ss/campus/config.py` | 新增 `DEFAULT_LOGIN_ENABLED = False`、`CampusConfig.login_enabled`、校验器 `_login_enabled`（**只接受真正的 TOML 布尔值**，字符串 `"false"` 视为非法并回落，避坑真值陷阱）；`load_campus_config` 接入 `_pick` |
| `ss/server/app.py` | 局部闭包 `_login_disabled()` / `_login_refused()`。`/v1/cloud/status` 恒报未登录（`signed_in=False`、`telemetry_enabled=False`）；`/v1/cloud/login`、`/v1/cloud/logout` 返 403 `signin_disabled`；`/auth/callback` 在兑换授权码**之前**返 403 HTML |
| `docs/config.example.toml` | 追加 `[campus]` + `login_enabled = false` 说明块 |

原实现体完整保留在早退分支之后 —— 置 `true` 即完整恢复上游一键连接流程（PRD §3.3.1 的「代码保留」+ F-3 可逆性）。`/v1/connectors/<name>/disconnect` 等本地连接器管理不受影响（已加用例锁定）。

**安全性**：`/v1/cloud/login` 在解禁前**不会**调用 `webbrowser.open`，也不会与云端交换任何凭据；`/auth/callback` 在解禁前不消费 `state`、不落盘 token。
