## 3. 关键实现说明

### 3.1 `flags.ts`（S1）

```ts
export const showLogin = () => flag("ocw.flag.login", false);
```

复用既有 `flag(key, fallback)`（localStorage），零新增依赖；不写 `config.toml`（ADR-04 扁平 KV 陷阱）。

### 3.2 `Sidebar.tsx`（S2）

| 子项 | 改法 |
|---|---|
| 账户菜单未登录分支 | `cloud?.signed_in ? (…) : showLogin() ? (未登录提示 + 登录按钮) : null` |
| 登出菜单项 | `cloud?.signed_in && showLogin() && …` |
| 账户行文案 | `showLogin() ? t("sidebar.not_signed_in_row") : t("sidebar.local_workspace")` |

`sidebar.local_workspace`（「本地工作区」/「Local workspace」）为本次 zh/en 同步新增的 1 个 key，保持 `locales.test.ts` 的 key 集合严格相等门禁。

### 3.3 `Onboarding.tsx`（S3）

登录带整块（`signin_for_oneclick` 文案带 + `ob-cloud-signin` 按钮 + 已登录态 `ob-tools-signedin`）包 `showLogin() &&`；footer 双态改判 `cloud?.signed_in && showLogin()`，关闭时落到「继续（不登录）」分支，step 1 → step 2 仍可正常推进。step 1 的 provider 表单（仅 API Key）**保留**（PRD §3.3.3 边界定义）。
