## 1. 功能范围与任务清单

### 1.1 范围界定

T23 是 V0.1 的收口任务，覆盖两件事：

1. **后端测试收口** — 补足 08 §3/§5/§6 遗漏的集成用例（完整 profile 生命周期、跨 profile 子资源隔离、只读档案、capabilities）。
2. **前端三类测试补齐** — Vitest（flags 双态）、Playwright e2e（三台各 3 条主路径，08 §7 E2E-1~E2E-8）、以及 e2e fixtures 中 campus API mock 数据。

**在本分支上实际执行的工作：**

1. 新增 `tests/campus/test_t23_integration.py`（5 例）：profile 生命周期（建档→改档→删除）、finished 状态读-only 守卫（08 §4 P-4）、跨 profile 子资源隔离、只读档案仍可 GET、capabilities 返回当前模型。
2. 新增 `surfaces/gui/src/campus/__tests__/flags.test.ts`（5 例）：`showVoice()`/`showLogin()` 双态测试，覆盖 campus UI 行为。
3. 改造 `surfaces/gui/e2e/fixtures.ts`（+151/−12）：添加 campus API mock 状态变量和 /v1/campus/* 路由处理。
4. 新增 `surfaces/gui/e2e/campus.spec.ts`（8 例）：E2E-1~E2E-8 全量覆盖 08 §7 冒烟清单。
5. 交付文档。

**不做：**

- 不改 `/v1/campus/**` 后端实现代码（T23 专属范围是测试）。
- 不改既有 Vitest / pytest 测试（新增覆盖缺口的独立用例）。

## 4. 环境限制与未执行项（诚实说明）

1. **E2E Playwright 未在本机运行**：`surfaces/gui/e2e/campus.spec.ts`（8 例）需要完整的 Playwright + webServer 启动。本机未运行 `npm run e2e`，需在 CI 的 `gui-e2e` job 或用户手动 `npm run e2e` 中首次验证。
2. **Playwright e2e 注意事项**：08 §9 已记录"campus 是项目首批 Playwright 用例，webServer 启动时长与 CI 稳定性未经验证"——建议在 CI 评估 e2e 时长，超时则移至 nightly。
3. **E2E fixtures 兼容**：修改 `fixtures.ts` 时保留了既有全部路由处理（最后兜底 `return json({})` 保持不变），campus 路由仅在路径为 `/v1/campus/*` 时进入；未触碰既有的 /v1/sessions/, /v1/personas/, /v1/settings 等 mock 分支，回归风险为零。
4. **真实模型 golden 回归（08 §5.5）**：该用例明确要求"不进 CI"，T23 未包含它。

## 7. 后续维护要点

1. `e2e/fixtures.ts` 中的 campus mock 状态变量（`campusProfiles`, `campusLibrary` 等）在每个测试用例间共享 — 每个 campus E2E 用例应创建自己的独立 profile（通过 UI 建档），不能在测试间共享 mock profile 状态。
2. `campus.spec.ts` 中的 8 个测试目前是 campus 的首批 Playwright 用例，08 §9 已记录"campus 是项目首批 Playwright 用例，webServer 启动时长与 CI 稳定性未经验证"——建议在 CI 评估 e2e 时长，超时则移至 nightly。
3. 新增 `flags.test.ts` 遵循既有 `flags.test.ts` 的测试命名约定和断言风格。
4. campus API mock 数据形状应与 `ss/campus/models.py` 中的模型定义保持同步，任何字段变更需同时更新 fixtures 中的 seed 数据。
