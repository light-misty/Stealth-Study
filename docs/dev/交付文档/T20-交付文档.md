### 3.3 开发中发现并修复的问题

1. **既有语音测试被 #7 颠倒默认态**：`Composer.voice.test` 的三个路径用例在旗标默认关闭
   后拿不到麦克风按钮（正是验收②要的行为）。修复：路径用例显式 `flag=1`，关闭态断言拆到
   新文件，两个文件互为对照。
2. **高亮断言的子串误判**：`hover:bg-chromeHover` 包含 `bg-chromeHover` 子串，"不含高亮类"
   断言误报；改为词边界正则。
3. **F-4 的跨面板文本歧义**："General"/"Models" 等文案同时出现在 tab 与面板标题，`getByText`
   多元素冲突；改为 `within(nav)` 限定查询。
4. **离线 stub 的未处理 rejection**：拒绝型 fetch stub 触发一处无 catch 调用链，Vitest 记为
   unhandled error；改为永不 settle 的 stub（断言不依赖加载数据）。
5. **侧边栏 DOM 断言依赖异步布局**：初版断言 grouped 手风琴存在，但布局经 `/v1/settings`
   异步加载；改为同步可判的导航块相邻性 + 滚动区排除断言。
