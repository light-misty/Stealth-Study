## 1. 功能范围与任务清单

07 §4 T10 点名「CET 组 14 个端点」：定级测评（CET-01，中断续做）、词汇（CET-02）、听力文本
精听（CET-03，无 STT）、作文/翻译批改挂 C1、常见错误 TOP3（CET-12）、模考状态机（CET-13）。
其中 03 §4.3 的映射表（§7 末尾）把 CET-09/10/12 指到 C 组端点——C 组在 07 中未被点名给任何
任务（T09 交付文档 §5-13 已登记此缺口），且 T10 的两处交付直接依赖它（写译批改必须挂 C1、
CET-12 就是 C4），故本阶段一并交付，**实际交付 18 个端点**：

### 3.3 开发中发现并修复的问题

1. **同秒写入分页乱序**（store 层）：`created_at` 只到秒，同秒多行时 `order_by="created_at DESC, id"`
   依赖 uuid 的字典序，分页可能乱序。`store._compile_order_by` 白名单放行 `rowid`，A1/E2/C3/G1/C4
   的排序统一改为 rowid 断尾。
2. **F4 折算常量算错**：写译段初版写 212.5，"三项目标之和 == 目标总分"用例捕获，修正为 213。
3. **`test_campus_flow.py` 路由清单**：T09 的 16 端点等式断言随 T10 扩为 `T09_ENDPOINTS + T10_ENDPOINTS`
   共 34 端点 + `/health`，保持"漏注册/方法写错/路径漂移即红"的门强度。

## 5. 与文档的差异登记

1. **F13 请求体**（03 §4.6 表格标"—"）：暂停时长必须从客户端到达，实现为
   `{"seconds": int}`（`gt=0` 且 ≤180）。03 的"累计 paused_seconds ≤180"与 PRD 的"可暂停一次"
   取更明确的 03 口径（累计），多次短暂停只要合计 ≤180 即可。
2. **F11 为纯读派生**：03 说"服务端时间重算"，实现为不落库的派生字段；阶段推进是显式 F12。
   差距：若前端在阶段到期后不调用 F12，收卡锁不落库（后续作答不被拦）。如需"到期自动收卡"，
   需要后台定时器或在 F11/读路径写库，建议 T23 集成测试阶段决策。
3. **F12 的 `to` 取全枚举**：03 字面只列 `listening|reading_translation`，但其错误表对
   `ILLEGAL_STAGE`/`STAGE_LOCKED` 定价——非法目标必须可表达才有这两个码。schema 层拒绝非枚举值
   （422），409 语义交给 service。
4. **F14 分项得分率分母只含已作答题目**：`mock_exam` 与题库无关联存储，未作答的题无法归卷；
   分母虚高比"分母缺失"更误导，故 `max` 累计已作答题目的分值。若要整卷分母，需 02 增加
   mock-题目关联表（建议登记到 T14 导出导入或 V0.2）。
5. **F14 估分口径**：题库分值直接累加（客观题判分得分、band 制题型按 E5 落库的档位分），
   不做二次 710 折算——导入真题自带官方分值，二次折算只会制造精度假象。
6. **F6 的 GET 是写语义**：刷新 `last_review_date` 落库，故挂 `get_writable_profile`（03 表格
   未标注，前端需知悉 finished 档案调 F6 会 409）。
7. **F9 助记写入 memories**：走 `ss/memory` 既有链路（Scope），01 §4.2 的"campus 只调既有
   memory 链路"约束满足；`manager` 调用边（`model`/`get_settings`/`provider`）沿用 T09 §5-1
   的登记，`ManagerCaller` 与 `ManagerGrader` 同边，仍建议确认后补进 01 §4.2。
8. **C 组归属**：07 仍未给 C 组端点点名任务，本次随 T10 交付并在此登记；B/D 组继续缺归属
   （D4-D6 由 T13 承接复习队列）。
9. **store.insert 不自动补 `last_wrong_at`**（T09 移交要点 4 的实例）：`_file_mistake` 显式落值。

## 6. 移交 T11-T14 的接口要点

1. **模考状态机复用**：`MOCK_STAGE_ORDER`/`MOCK_STAGE_MINUTES`/`SUBJECT_STAGE`（科目 → 阶段）
   /`SUBJECT_SECTION`（科目 → 估分分项）都在 `service.py` 模块级；CET 专属，考研/证书台不要引用。
2. **ManagerCaller**：非批改类单次模型调用（出题/助记/计划）统一走它，参数与批改链同源
   （温度 0 / 90s / `model_for_task` 解析链）；失败映射 `MODEL_TIMEOUT`(504) /
   `MODEL_OUTPUT_INVALID`(502)，未配置模型前置拦 `MODEL_NOT_CONFIGURED`(409)。
3. **E5 的收卡拦截**已内建：`_assert_mock_open(mock, question)`。T13 的复习队列如需区分
   "模考中的错题"，`attempt.mock_exam_id` 非空即模考场景。
4. **F14 已做模考场景的错题入本**（幂等按 attempt_id），练习场景（无 mock_exam_id）的判负
   入本仍按 T09 移交要点 3 留给 D 组/T13；`_file_mistake(profile, attempt_row)` 可直接复用。
5. **数据口径**：`by_section` 键为 `listening/reading/writing_translation`（与 F4 的
   `scores`、A8 的 capabilities 同一词表）；`locked_stages` 是 JSON 字符串列，读取方用
   `json.loads`。
6. **端点追加方式**与 `_call`/`_async_call` 错误翻译、`ERROR_SPECS` 先行登记等约定不变
   （T09 交付文档 §6-1）；路由清单门 `test_campus_flow.py` 的 `T10_ENDPOINTS` 需随 T11/T12
   继续追加。
