## 6. 移交 T08 / T09 的接口要点

1. `GradingEngine(provider, model_picker, *, start_level, call_budget, timeout_s, temperature)`：`provider` 为 `ProviderClient`（`complete(*, model, messages, **settings) -> AssistantTurn`），`model_picker` 用 `models.pick(kind, track_type) -> (recommended, fallback)`，`config.resolve_task_model` 可作配置覆盖的 picker 封装（06 §2.2）。
2. `await engine.grade(req)` 是 async，内部用 `asyncio.to_thread` 包裹阻塞 `complete`；service 直接 `await` 即可，无需再套线程（T09 C1 的"同步请求 + 线程内完成"）。
3. 一次 C1 调用链（06 §1.1）：service `INSERT attempt(status=pending)` → `await engine.grade()` → `UPDATE attempt(grading_json, degrade_level, model_used)`。
4. `grading_json` 落库白名单（02 §4.13）：去 `ok/model_used/usage/fail_reason`（服务端字段），`degrade_level` 单列存 `attempt.degrade_level`；`degrade_trace` 并入 `grading_json._degrade_trace`；`degrade_level>=1` 时响应 `notice` 已由引擎填充非空。
5. kind 路由：`essay`(L0/L1/L2)、`translation`(L0/L1)、`short_answer/essay_material/lesson_plan/practical`(L0)；`custom_rubric` 非空时覆盖 rubric 全文（CERT-07-4）。
6. 错误语义：引擎层不抛业务异常；L3 失败时 `ok=False` 且 `fail_reason` 为 `MODEL_TIMEOUT`/`MODEL_EMPTY`，T09 据此返回 03 文档错误码 `MODEL_TIMEOUT` 等。
7. 一致性测试切换：T21 `SKILL.md` 落盘后，把 `test_rubrics_consistency._rubric_body` 的取源从 `docs/dev/05` 文档换成对应 `personas/builtin/<id>/skills/<name>/SKILL.md`，断言结构不变即可无缝升级为逐字比对硬门禁。
