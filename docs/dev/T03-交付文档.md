## 3. 冒烟设计与执行

### 3.1 临时挂载形态（与 T06 正式形态一致）

spike 按文档指定的 2 行插入 `create_app()` 内 `app = FastAPI(...)` 之后：

```python
    from ss.campus.routes import build_campus_router  # T03 SPIKE-3 temporary mount
    app.include_router(build_campus_router(manager))
```

临时 `ss/campus/routes.py` 为文档要求的 10 行量级路由工厂：`APIRouter(prefix="/v1/campus")` + 单个 `GET /health` 端点。补丁/还原均以源码文本精确锚定（唯一 `app = FastAPI(` 行），锚点缺失、重复应用、非连续补丁一律抛 `SpikeError` 拒绝带病执行。

### 3.2 执行链路说明（GUI 等价性）

Tauri GUI 的后端即 `python -m ss.server.run` 启动的本地 sidecar：`main()` → `build_app()` → `create_app()` → `uvicorn.run()`。本 spike 子进程使用**同一 `build_app` 入口**（仅以哨兵文件触发 `should_exit` 实现可校验的优雅停机，替代 GUI 的窗口关闭信号），启动参数、token 注入（`COWORKER_API_TOKEN` 环境变量）、状态目录隔离方式均与 sidecar 一致。因此「GUI 启动 → health 200」的验收以 sidecar 同链路冒烟等价覆盖；前端界面点通项（会话/设置/自动化的**UI** 操作）按任务边界归 T20/T23 的 e2e 覆盖。

### 3.4 单测（`tests/campus/test_spike_mount.py`，6 用例全绿）

按 TDD 先写测试（RED：模块缺失 6 errors）后实现（GREEN）：

1. 临时路由形状：挂载到裸 FastAPI 后 `/v1/campus/health` 返回 200 与约定 JSON；
2. **apiToken 中间件覆盖挂载路由**：真实 `create_app()` + `include_router`，无 token/错 token 401、对 token 200，且 `/v1/sessions`、`/v1/settings`、`/v1/automations` 在 token 下正常；
3. 补丁精确插入：恰好 2 行、紧跟 `app = FastAPI(` 锚点之后，重复应用抛 `SpikeError`；
4. 还原无损：补丁 → 还原后与原文逐字节相等；
5. 防御性失败：对无锚点文本应用/还原补丁均干净抛错，绝不盲改；
6. 临时包自包含：`__init__.py` + `routes.py` ≤20 行、含 `build_campus_router` 与 `/v1/campus` 前缀。

### 4.2 既有失败的基线对照（数据诚实说明）

用 `git archive 4a54991` 抽取基线提交到仓库外目录、以同一 venv 复跑同样用例，失败完全复现：

- `test_server.py` 的 WS 用例失败于 TestClient 的 anyio 通道（`ClosedResourceError`）及 POSIX-only 断言（`time.tzset`、0600 文件位）；
- `test_automation.py` 失败于子进程拉起 `coworker` 可执行文件（`FileNotFoundError: [WinError 2]`，本机未安装该 CLI）。

即这 31 个失败为**本机 Windows 环境的既有问题**（POSIX 假设用例 + 缺 CLI），与 T03 的纯增量改动无关——且本阶段对既有源码的 diff 为零，结构上也不可能引入回归。该清单移交 T04 报告「已知限制」，不阻塞决策门。

### 4.3 spike 自身发现并修复的问题

| 问题 | 修复 |
|---|---|

## 5. 对 T06 的交接结论

1. **挂载点确认**：`create_app()` 内 `app = FastAPI(...)` 行后即为正式挂载位；中间件（token 校验、CORS）对 `include_router` 子路由自动生效，T06 的 profile_id 依赖注入可直接依赖该行为。
2. **无需 try/except 预案**：挂载失败仅发生在 import/工厂调用阶段，本 spike 已证明该路径在真实启动链路中零风险。
3. **注意事项**：本仓库工作副本为 CRLF（`core.autocrlf=true`），T06 打 2 行补丁时锚点检测应同样使用 `strip()` 匹配；`ss/campus/` 正式落库后，spike 的临时包写入逻辑与正式包**不共存**（spike 前置检查到 `ss/campus` 已存在时应拒绝执行）。
