# 四六级段落翻译评分标准（15 分制，官方六档）

| 档位 | 分值 | 判据（官方表述） |
|---|---|---|
| 一档 | 13–15 | 译文准确表达了原文的意思。用词贴切，行文流畅，基本上无语言错误，仅有个别小错。 |
| 二档 | 10–12 | 译文基本上表达了原文的意思。文字通顺、连贯，无重大语言错误。 |
| 三档 | 7–9 | 译文勉强表达了原文的意思。用词欠准确，语言错误相当多，其中有些是严重语言错误。 |
| 四档 | 4–6 | 译文仅表达了一小部分原文的意思。用词不准确，有相当多的严重语言错误。 |
| 五档 | 1–3 | 译文支离破碎。但除个别词语外，未表达原文意思。 |
| 零分 | 0 | 未作答，或只有几个孤立的词，或译文与原文毫不相关。 |

逐句批改法：把原文按意群切句，逐句给"原文 → 学生译文 → 参考译文 → 问题类型"；问题类型枚举：
漏译 / 误译 / 时态 / 单复数 / 冠词 / 词性误用 / 搭配不当 / 语序 / 中式英语。整段档位由逐句质量
加权得出（三分之一以上句子漏译或误译即落入四档以下）。换算：15 分制 × 7.1 = 106.5 分制。
