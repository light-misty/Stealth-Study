# 错题归因五分类（固定枚举，与 rubrics.py 的 ATTRIBUTION_TAXONOMY 一致）

| 归因 | 判定标准（满足即归此类） |
|---|---|
| 概念不清 | 对知识点本身理解错误或缺失——换一种问法仍会错 |
| 审题失误 | 知识点会，但看错/漏看题目条件、答非所问 |
| 计算或操作失误 | 思路对，执行环节出错（算错、操作步骤错、抄错） |
| 超纲或不熟 | 考纲边缘内容或首次接触的题型，谈不上掌握 |
| 时间不够 | 会做但没做完/被迫乱选——正确率在限时外可复现 |

输出固定格式：`建议归因：<类别>｜依据：<一句话，引用题目中的具体证据>｜置信：<高/中/低>`。
规则：① 五类互斥，选最主导的一个；② 证据必须是题目原文或学生作答中的具体内容，不得空泛；
③ 置信为"低"时明确建议"待确认"，让用户在错题本中手动选择；④ 你只输出建议——最终归类由
用户确认后落库，不要声称"已记录"。
